# Combine Igbo Datasets

## Overview
A collaborative data project where three team members each sourced a separate Igbo-language dataset. This notebook combines and cleans those individual datasets into a single unified dataset for downstream use (e.g. translation, NLP, or language model training).

## Process
- Collected 3 separate Igbo datasets from different team members
- Merged the datasets into one combined file
- Cleaned and standardized the combined data

## Tech Stack
- Python
- pandas
- Google Colab

## How to Run
1. Open `Combine_Igbo_Datasets.ipynb` in Google Colab
2. Mount your Google Drive (datasets should be accessible there)
3. Run all cells in order to produce the combined, cleaned dataset

## Output
Produces a combined English-Igbo dataset for further use.
